# CASCADE Data Audit — 2026-05-13

## TL;DR

Programmatic re-audit of the entire mined-Cas13 catalog (110 entries in
`metadata/cas13_variants.db` and 8 candidates in `CASCADE_CANDIDATE_REPORT.md`)
showed **the majority of pipeline-classified Cas13 hits are mis-annotated
non-Cas13 enzymes**. The active pipeline has been quarantined to a verified
3-sequence ground-truth set while corrected mining is rebuilt.

## Underlying pipeline bugs (to be fixed in next commits)

- **B-2** `scripts/mining_v2.py` HEPN regex is `R.{3,8}H` — must be canonical `R.{4,6}H`.
- **B-9** `scripts/mining_v2.py:_finalize_array` does not store `array_start`/`array_end`,
  so MinCED-derived DRs cannot be assigned to ORFs by genomic distance; the
  pipeline falls back to k-mer guessing, which finds tRNA stems and other repeats.
- **B-10** No anti-signature filter (signal peptides, GH3, MetH, MBL, AAA+).
- **B-13/14** No BLASTP (or DIAMOND-blastp equivalent) reciprocal verification
  against `data/cas13_reference_db.fasta`.
- **B-1** Rust `cascade_structscore::HepnDistance` measures Cα-Cα instead of
  the catalytic-Hist Nε2-Nε2 distance.

## How to reproduce / extend

- `scripts/quarantine_non_cas13.py` — full quarantine driver (idempotent: run twice = no-op).
- `scripts/quarantine_finish.py` — finishes the per-ORF subdirectory cleanup
  (was needed because Step 8's WAL-handle release race-condition crashed the first run).
- Per-quarantine manifest with full action log lives at
  `quarantine/non_cas13_audit_20260513/MANIFEST.md` (gitignored).
- Original data is preserved as backups in the same quarantine tree
  (`*.bak_audit_20260513` for in-place trims; full directory moves for the rest).
